# Webライター ポートフォリオ(テンプレート)

GitHub Pagesでそのまま公開できる、Webライター向けシングルページ・ポートフォリオのテンプレートです。
ビルド不要(HTML + Tailwind CSS CDN + プレーンJavaScript)。

## 構成

```
site/
├── index.html      本体(全セクション)
├── js/script.js    モバイルメニュー・実績フィルタ・お問い合わせフォームの挙動
└── README.md       このファイル
```

## ローカルで確認する

`index.html` をダブルクリックしてブラウザで開くだけで確認できます。Tailwind CSS・Google Fonts・実績画像はすべて外部URL読み込みのため、サーバーなしでも見た目・動作(メニュー開閉、実績タブ切り替え、フォームのダミー送信)は問題なく確認できます。

サーバー経由で確認したい場合(お問い合わせフォームをFormspree等の`fetch`送信に置き換えたときの動作確認など)は、以下でも起動できます。

```sh
cd site
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くか、VS CodeのLive Server拡張を使ってください。

## カスタマイズのしかた

`index.html` 内の `<!-- ▼ここを差し替え: ... -->` というコメントが、書き換えが必要な箇所の目印です。
現在入っているお名前・経歴・実績・料金・画像はすべてダミーです。実際の内容に置き換えてから公開してください。

- ロゴ・お名前・キャッチコピー・自己紹介文
- 対応可能業務・使用ツール
- 執筆実績(タイトル・担当範囲・成果・記事リンク・画像)
- 単価目安・稼働条件
- SNSリンク(X・note)

実績カードの画像は [Picsum Photos](https://picsum.photos/) のダミー画像です。差し替える場合は `img` タグの `src` を実際の画像URL(またはローカル画像)に変更してください。

## お問い合わせフォームについて

現在フォームはダミー動作です(送信ボタンを押すと成功メッセージが出ますが、実際にはどこにも送信されません)。
GitHub Pagesは静的サイトのため、実際に送信を受け取るには [Formspree](https://formspree.io/) などの外部フォームサービスと連携する必要があります。手順は `js/script.js` 内のコメントに記載しています。

## GitHub Pagesでの公開

1. このリポジトリをGitHubにpushする
2. GitHubリポジトリの Settings → Pages で、公開ブランチ(例: `main`)とルートディレクトリを指定する
3. 発行されたURLでサイトを確認する
